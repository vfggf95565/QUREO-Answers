# QUREO-Answers

ملفات إجابات بصيغة JSON لدورتَي **JavaScript** و**Python** على منصة Qureo (QUREO for SPRIX LEARNING).
هذا المستودع **بيانات فقط**: لا يحوي سكربتات ولا أدوات.

> ⚠️ **إخلاء مسؤولية:** مشروع شخصي غير تابع لـ Qureo أو SPRIX أو أي جهة أخرى، وغير مدعوم منها. أسماء المنصة وأسئلتها ملك لأصحابها. للاستخدام الشخصي والتعليمي.

## 📂 الهيكل

```
QUREO-Answers/
├─ JavaScript/   1.json  2.json … 54.json
└─ Python/       1.json  2.json …
```

- **اسم المجلد** = الدورة، بهذا الحرف تماماً (`JavaScript` · `Python`).
- **اسم الملف** = رقم المستوى بلا أصفار بادئة: `21.json` وليس `021.json`.
- رقم المستوى يُحسب من رقم الفصل في رابط المنصة:

| الدورة | رابط الفصل | المستوى |
|---|---|---|
| JavaScript | `/chapter/90021` | 90021 − 90000 = **21** |
| Python | `/chapter/511003` | 511003 − 511000 = **3** |

رابط الملف الخام:
```
https://raw.githubusercontent.com/vfggf95565/QUREO-Answers/main/<الدورة>/<المستوى>.json
```

## 🗄️ صيغة الملف

```json
{
  "level": 21,
  "lessons": {
    "1": {
      "questions": {
        "1": { "question": "نص السؤال", "answer": { "type": "code", "value": "let x = 1;" }, "label": "الاول" },
        "u1": { "question": "سؤال بلا رقم داخل الدرس", "answer": { "type": "text", "value": "ينتج عنه خطأ" } }
      },
      "_order": ["1", "u1"]
    }
  },
  "review": {
    "questions": { "1": { "question": "…", "answer": { "type": "text", "value": "&&" }, "label": "الاول" } },
    "_order": ["1"]
  }
}
```

| الحقل | المعنى |
|---|---|
| `level` | رقم المستوى (يطابق اسم الملف) |
| `lessons.<n>` | الدرس رقم n؛ و`review` مراجعة المستوى |
| `questions.<k>` | `k` رقم السؤال، أو `u1` و`u2`… للأسئلة غير المرقّمة |
| `_order` | ترتيب ظهور الأسئلة في الصفحة |
| `answer.type` | نوع الإجابة (الجدول أدناه) |

### أنواع الإجابات

| النوع | المحتوى | معناه |
|---|---|---|
| `text` | `value` | اختيار من متعدد (نص الخيار) |
| `multi` · `multi_select` | `values` | عدة خيارات |
| `code` | `value` | كود كامل |
| `partial` | `answer_code` · `full_code` | جزء يُكتب داخل كود جاهز |
| `fill` | `blanks` · `template` · `full_code` | فراغات داخل الكود |
| `sort` | `order` | ترتيب عناصر |
| `action` | — | تشغيل الكود فقط |
